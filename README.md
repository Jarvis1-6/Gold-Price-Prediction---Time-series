# Gold-Price-Prediction---Time-series
Gold price forecasting using ARIMA Time series analysis in R.
# Overview
This project uses historical gold price data from Kaggle to forecast future gold prices using ARIMA time series modelling in R.

# Key Features
1. Data Cleaning and Preprocessing
2. Exploratory Data analysis
3. Price Trend and seasonality analysis
4. ARIMA Model selection
5. Gold price forecasting
6. Data Visualisation

# Tools used
R, ggplot2, magrittr, forecast, tseries

# Results
The ARIMA(2,1,2) model was selected based on AIC and successfully captured historical trends and seasonality patterns for forecasting future gold prices.
